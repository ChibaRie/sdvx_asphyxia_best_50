# Background assets

## `sdvx_exceed_gear_key.jpg`

- **Source:** official SOUND VOLTEX EXCEED GEAR site (Konami Amusement),
  `https://eacache.s.konaminet.jp/game/sdvx/vi/top_banner/og_summary.jpg`
- **Retrieved:** 2026-11-11
- **Used for:** the hero key visual in the generated Best 50 poster.
- **Rights:** artwork © Konami Amusement. This file is **not** covered by the
  repository's MIT license. It is bundled only as a background for this
  non-commercial, personal fan scorecard. Do not redistribute the artwork for
  commercial use; replace it with your own licensed image if you do.

The renderer treats this file as optional. If it is removed, `render_theme.py`
draws an original SDVX-flavoured stand-in (a cyan "del" mark, grid and laser
atmosphere) with the same layout, so the generator still works offline.
